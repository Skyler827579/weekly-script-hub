案例判断

适不适合做口播
非常适合做出海口播。它有具体门店面积、SKU 数量、IP 商品占比、覆盖市场和海外收入增速，既能讲品牌升级，也能讲东南亚本地化。需要注意的是，单店客流、销售额和投资回收期并未完整公开，不能把大店开业直接等同于盈利成功。
为什么值得讲
这个案例打破了一个常见误区：品牌出海不是把国内店铺复制到国外。名创优品早期靠高性价比和快速上新建立认知，进入东南亚更深阶段后，开始用更大的店、更密集的 IP 商品和更强的视觉体验争夺核心商场位置与年轻消费者时间。它卖的不只是商品，而是逛店、拍照、收藏和社交分享。
最值得讲的问题
为什么一个原本依靠低价小商品和高周转的品牌，在东南亚扩张时反而要投资面积更大、装修更重、体验更复杂的旗舰店？
最一针见血的角度
名创优品在东南亚卖的已经不只是便宜，而是把便宜商品装进一个值得专门去逛的 IP 场景。供应链负责让东西买得起，IP 和空间负责让用户愿意进店、停留和分享。

为什么它能做成

  • 它先用高性价比降低购买门槛，再用 IP 提高情绪价值。同样是毛绒、盲盒、杯子和家居小物，消费者愿意为熟悉角色、限定系列和收藏感停留更久，也更容易从计划外浏览变成冲动购买。
  • 它把门店从销售点改造成流量内容。马来西亚 MINISO LAND 设置 15 个主题零售与互动区域，还有大型角色装置和拍照点；门店本身可以不断产生 TikTok、Instagram 和本地社媒素材，线下租金同时承担销售和获客两种功能。
  • 它选择核心商场而不是只追求低租金。马来西亚店位于 Sunway Pyramid，新加坡 MINISO FRIENDS 位于 VivoCity。高客流地标帮助品牌接触家庭、游客和年轻消费者，也让大店更像目的地，而不是路过才买的小铺。
  • 它没有用一个店型硬推所有国家。MINISO LAND 更大、更像 IP 游乐场；MINISO FRIENDS 相对灵活，可以进入新加坡、越南等不同商业环境。这种多店型组合让品牌根据城市密度、商场面积和消费能力调整。
  • 它用全球授权 IP 降低文化翻译成本，同时培养自有 IP。Sanrio、Monchhichi 等角色在东南亚已有认知，能快速带来客流；YOYO 等自有角色则帮助品牌逐渐减少只为外部授权方导流的问题。

最值得带走的洞察

东南亚出海进入第二阶段以后，竞争不再只是把中国供应链价格带过去，而是如何把供应链、IP、空间和本地流量组合成新的消费理由。便宜解决第一次购买，体验和角色认同决定消费者会不会专门来、拍下来并再次回来。

不要怎么讲

不要说名创优品已经靠东南亚大店全面实现高利润，也不要把海外收入增长全部归因于 MINISO LAND。公开资料能证明门店扩张、店型升级和海外收入增长，但不能单独证明每一家大店的投资回报。也不要把 IP 联名讲成零风险，授权费用、库存预测、商场租金和潮流过期都可能侵蚀利润。

可带走的观点

  • 出海不是复制国内店型，而是重新设计当地消费者进入、停留和分享的理由。
  • 供应链让商品保持可负担，IP 与空间则负责提高客单、停留时间和社交传播。
  • 旗舰店可以同时承担销售、品牌展示和内容获客，但高租金与重装修要求更强的运营效率。

完整口播稿

一个靠十几块、几十块小商品起家的品牌，为什么到了东南亚以后，反而把店越开越大？

今天讲一个很典型的东南亚出海案例：名创优品的 MINISO LAND。

2026 年，名创优品开始在新加坡、马来西亚、越南和印尼继续扩张 MINISO LAND 和 MINISO FRIENDS 两种新店型。

其中马来西亚首家 MINISO LAND 开在 Sunway Pyramid，面积大约一千七百平方米，是当时东南亚最大的 MINISO LAND。

这家店里有超过八千件商品，十五个主题零售和互动区域，而且超过百分之七十的商品，跟授权 IP 或名创优品自己的角色有关。

新加坡 VivoCity 的 MINISO FRIENDS，也放进了三千二百多个 SKU。

如果你还把名创优品理解成一家低价杂货店，这组数字就有点反常。

低价零售讲究高周转、低装修、快速开店。

为什么出海以后，它要做面积更大、装修更重、体验更复杂的旗舰店？

因为名创优品在东南亚卖的，已经不只是便宜。

它真正想卖的是一种值得专门去逛、去拍、去分享的 IP 消费体验。

第一层逻辑，是供应链负责价格，IP 负责情绪价值。

名创优品原来的优势，是把大量日用小商品做得足够快、足够多、价格也容易接受。

但这个模式很容易被复制。

如果消费者只记得便宜，那下一家更便宜的店出现，他就可能马上离开。

IP 商品解决的是为什么偏偏买这一件。

同样是一个毛绒玩具、一个杯子、一个盲盒，有 Sanrio、Monchhichi，或者自己喜欢的角色以后，它就不再只是一个功能商品。

它会变成礼物、收藏、情绪安慰，甚至是社交身份。

所以供应链让消费者买得起，IP 让消费者愿意多买一件。

第二层逻辑，是大店本身变成了内容。

马来西亚这家店不是把八千件商品塞进货架就结束了。

它做了十五个主题区域，还有大型角色装置和拍照点。

消费者进店以后，不只是找商品，也会拍照、逛主题区、寻找限定款，然后把内容发到 TikTok、Instagram 或本地社交平台。

这时候，门店租金不只是购买一个销售空间。

它同时购买了线下客流、品牌展示和社交媒体素材。

一家普通小店，只有经过门口的人知道。

一家能被拍、能被分享的大店，可能会被更多没有经过门口的人看到。

第三层逻辑，是它在抢东南亚核心商场里的目的地位置。

马来西亚店开在 Sunway Pyramid，新加坡店开在 VivoCity。

这类商场本身就有家庭、游客和年轻消费者的稳定流量。

大店的作用不是让用户顺路买两样东西，而是让用户把它当成商场里值得专门去的一站。

对东南亚市场来说，这一点尤其重要。

天气、城市交通和消费习惯，让大型商场不仅是购物场所，也是家庭休闲、约会和周末娱乐空间。

名创优品把零售做得更像轻量娱乐，才能在商场里争夺消费者停留时间。

第四层逻辑，是它没有拿一个店型硬推所有国家。

MINISO LAND 面积更大，更像一个 IP 游乐场。

MINISO FRIENDS 相对灵活，可以根据商场面积和城市消费能力调整。

这意味着出海不是把国内的一张施工图复制十遍，而是保留供应链和品牌核心，再根据当地租金、客流、城市密度和消费习惯重新组合。

第五层逻辑，是先借全球 IP 获客，再慢慢培养自己的角色。

Sanrio 这类授权 IP 在东南亚已经有认知，消费者不需要重新教育。

但如果永远只卖别人的角色，品牌就会承担授权成本，也很难把所有用户资产留给自己。

所以名创优品也在推自己的 YOYO 等角色。

新加坡还做过 YOYO 的商场活动。

这是一条更长的路：先借成熟 IP 把人带进店，再让自有 IP 逐渐获得曝光。

从公司数据看，这套海外扩张至少正在带来增长。

名创优品公布的 2025 年全年业绩显示，MINISO 品牌海外市场收入同比增长约百分之三十点五。

但这里要谨慎。

海外收入增长不能全部归因于 MINISO LAND，也不能说明每一家大店都已经赚到钱。

大店的风险也很清楚。

面积越大，租金、装修、人员和库存成本越高。

IP 越多，授权费用和潮流过期风险越高。

如果消费者只来拍照不购买，或者一个角色热度突然消失，重资产门店的压力会很快出现。

所以这套模式真正考验的，不是开出一间漂亮店，而是商品更新、库存预测、活动节奏和本地运营能不能持续。

这个案例对中国品牌出海最值得借鉴的，不是大家都去开大店。

而是出海进入第二阶段以后，便宜已经不够了。

你要重新回答三个问题。

当地用户为什么要专门来？

为什么愿意在店里多停留二十分钟？

为什么愿意把你的产品主动发到社交媒体？

名创优品给出的答案，是把供应链、IP、空间和商场流量绑在一起。

所以，名创优品在东南亚越开越大的真正原因，不是它忘了高性价比。

而是它开始用高性价比负责成交，用 IP 和体验负责品牌。

这才是这轮东南亚出海最值得带走的逻辑。
